# Mini Task Manager

Mini full-stack task manager with user authentication and task management.

## Tech Stack
- Backend: PHP
- Frontend: React
- Database: MySQL

## Requirements
- PHP 8+
- MySQL 8+
- Node.js 18+

## Setup

### Database

Create database:
```sql
CREATE DATABASE task_manager;
mysql -u root -p task_manager < backend/database/schema.sql
