# 🎨 Frontend – Mini Task Manager

This is the frontend application for the **Mini Task Manager** project.  
It is a single-page application built with **React**, consuming a REST API protected with JWT authentication.

---

## 🛠 Tech Stack

- React
- Redux Toolkit
- React Router DOM
- Axios
- CSS (responsive, no UI libraries)

---

## ✨ Features

- User registration and login
- JWT-based authentication
- Protected routes
- Task CRUD (Create, Read, Update, Delete)
- Inline task editing
- Task filtering by status (pending, in progress, done)
- Visual feedback messages (create, update, delete)
- Automatic logout on token expiration
- Responsive layout
- Header with logo and user context
- Logout button

---

## 📦 Requirements

- Node.js **18+**
- npm or yarn
